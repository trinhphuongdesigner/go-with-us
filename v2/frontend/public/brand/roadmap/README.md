# CareerMate roadmap assets

These SVG assets are copied from the CareerMate Milo Reference v2 handoff and remain vector assets in the application:

- `step-completed.svg`, `step-current.svg`, `step-upcoming.svg`, `step-goal.svg`: milestone platforms.
- `check-marker.svg`: completed marker.
- `goal-flag.svg`: final goal marker.
- `milo-contact-shadow.svg`: optional contact shadow.

The implementation uses semantic HTML for titles, status and periods. Text is not baked into these vectors.
